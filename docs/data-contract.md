# 课室使用分析资料约定

资料全部是本地合成业务记录，不含真实个人信息。`term-a` 为完整版本，`term-b` 保持业务值不变而调整表行次序，用于检验分析是否不恰当地依赖到达顺序；`limited` 保留登记资料并移除一类观测，表示证据不足的版本。版本内容不可就地修改。

- `sessions`：业务唯一键为 `session`。
- `bookings`：业务唯一键为 `learner, session`。
- `scans`：业务唯一键为 `learner, session`。

sessions 的时间是当日零点后的分钟，区间左闭右开；day 隔离不同日期。报名表示具备到课资格，不强制到课。刷卡区间表示到课且进、出时间各在所列闭区间内，入场不得晚于离场；人在课程以外不能占用该课程座位。教室容量约束针对同一 room、day 的共同占用，而不是每门课程各占一套容量。允许零时长刷卡。场地情景只替换 sessions 的 room 或 capacity，不改变证据。

字段之外不能从示例的编号顺序或随机生成规律推导业务关系。涉及权重、相关范围、模型支撑的判断必须使用明确登记的字段和业务假设。
