# 课室使用分析资料约定

资料全部是本地合成业务记录，不含真实个人信息。`term-a` 为完整版本，`term-b` 保持业务值不变而调整表行次序，用于检验分析是否不恰当地依赖到达顺序；`limited` 保留登记资料并移除一类观测，表示证据不足的版本。版本内容不可就地修改。

- `sessions`：业务唯一键为 `session`。
- `bookings`：业务唯一键为 `learner, session`。
- `scans`：业务唯一键为 `learner, session`。

sessions 的时间是当日零点后的分钟，区间左闭右开；day 隔离不同日期。报名表示具备到课资格，不强制到课。刷卡区间表示到课且进、出时间各在所列闭区间内，入场不得晚于离场；人在课程以外不能占用该课程座位。教室容量约束针对同一 room、day 的共同占用，而不是每门课程各占一套容量。允许零时长刷卡。场地情景只替换 sessions 的 room 或 capacity，不改变证据。

字段之外不能从示例的编号顺序或随机生成规律推导业务关系。涉及权重、相关范围、模型支撑的判断必须使用明确登记的字段和业务假设。

## occupancy_bounds 占用边界口径

- 刷卡的进、出闭区间会先裁剪到课程窗口；裁剪后无可行入场或离场时刻即判为矛盾记录。某条刷卡在 `[enter_hi, leave_lo)` 内的每个分钟必然在场（forced_minutes），其余分钟是否在场取决于尚未观察到的进、出选择。
- 未刷卡不等于缺席：未刷卡报名者可以全程缺席，也可以在课程窗口内安排单个连续到课区间。零时长到课（入场等于离场）计入人头、不产生座位分钟。
- 人头下界等于刷卡人数；上界还要计入至少能在课程窗口某一分钟到场的未刷卡报名者，被其他教室强制在场全程钉住的学员不计入。
- 房间分段的同时占用下界取强制在场分钟的最大同时占用；上界逐分钟枚举“可能到场且未被他处钉住”的学员数，再受该分钟生效容量约束。教室容量按同 room、同 day 的共同占用生效。
- 座位分钟（在场分钟数之和）的上下界由分钟级流守恒模型求解：在场变量满足流守恒、单人单教室与房间容量约束；松弛解出现分数时自动回退整数规划，结果中的 `seat_minutes_integer_fallback` 记录是否发生回退。
- 每个极值都是独立优化问题的解，通常对应不同的可行到课安排，禁止把不同极值拼成一张完整到课表。`limited` 移除全部刷卡后，所有下界退化为 0、上界退化为报名/容量口径，用于呈现证据不足而非无人到课。
- 场地情景（scenario）只覆盖 sessions 的 room/capacity；若调整后强制在场人数超过新生效容量，配置判为无解并在 contradictions 中给出房间、日期、超容分钟与涉及学员。
